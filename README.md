# Daggerheart: Campaign Currency

Foundry VTT v14 module for the Daggerheart system (Foundryborne). Replaces the
fixed coins / handfuls / bags / chests with a per-world currency: any number of
denominations, any names, any conversion rates.

**Status:** early development, not usable yet.

## Installation (development)

Symlink this folder into your Foundry data directory:

```bash
ln -s /home/jezhik/Projects/DH-Currency <FoundryData>/Data/modules/daggerheart-currency
```

Then enable "Daggerheart: Campaign Currency" in your world.

## Requirements

- Foundry VTT v14
- Daggerheart system ≥ 2.11
- Optional: Daggerheart: Store, with currency mode set to "Disabled (Manual Only)"
