# Changelog

## 0.1.0 – unreleased

First version.

- World currency with up to 8 freely defined denominations and presets.
- Wallet in character and party sheets with relative input (`+n`/`-n`) and automatic change.
- Price scale (value of one rule handful), applied to the Daggerheart Store's price multiplier.
- Setup assistant for system and store settings.
- Migration of handfuls, bags and chests with preview and per-actor backup.
- English and German localization.
